Upload PayPal Activity CSV

Export your activity from PayPal and upload it here. Each row should be one payment with a Date and Name column — we'll count how many payments each person made and multiply by your weekly rate (set in Settings) to work out how much they've paid.

What happens next

  • Payments are grouped by the payer name PayPal reports, and counted per person.
  • Each payment is assumed to be one week at your current weekly rate.
  • We try to automatically match each name to a player (exact name/alias match, or a name we've matched before).
  • You'll get a review screen to manually match any names we couldn't resolve — useful if someone pays under a nickname, spouse's name, etc.
  • Any player who still owes money but has no matching PayPal payment in this file will be highlighted as missing.
  • Once you're happy with the matches, you can mark the covered weeks as paid directly from the review screen.
